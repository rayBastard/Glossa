# Built-in books (optional, not committed)

Put book files here as JSON and list them in `index.json` to show them on the
library shelf, e.g.:

```json
[{ "id": "rebreanu-adam-si-eva", "url": "books/adam-si-eva.json",
   "title": "Adam și Eva", "author": "Liviu Rebreanu", "lang": "ro" }]
```

Book JSON format: `{ "paras": [ { "t": "paragraph text" }, { "h": 1, "t": "Chapter title" } ] }`

Only add texts you have the right to distribute. Everything in this folder
except this README is git-ignored.
